      Las 2 reglas de oro

      1. En presente, con he / she / it el verbo lleva -s: I check → she checks.

      2. Después de can, will, would, should, must, might, don't, doesn't, didn't, to va el verbo tal cual: she can check, he didn't sign.

      Futuro con will: decides ahora, prometes, ofreces

      will + verbo (igual para todos): I'll check it · she'll call you

      Negativo: won't (= will not) · Pregunta: Will you…?

      Futuro con going to: planes ya decididos

      am / is / are + going to + verbo

      II'm going to measure it
      he / she / itShe's going to sign it
      you / we / theyWe're going to change it

      Hablando rápido suena "gonna": I'm gonna check it.

      Can / can't: poder, saber hacer

      can + verbo, igual para todos. Nunca "cans" ni "can to".

      I can do it · he can't sign it · Can you help me?

      Pasado: could / couldn't · I couldn't sign it.

      should + verbo = debería · You should ask the inspector.

      Have to: tener que

      I / you / we / they have to · he / she / it has to · pasado: had to

      Negativo: don't have to = no hace falta (no es prohibición).

      Órdenes (imperativo)

      El verbo solo: Check the part. · Negativo: Don't touch it.

      Para sonar amable: Can you check the part, please? · Could you…? · Would you mind + -ing?

      Ya / todavía no / alguna vez: have + participio

      I've / you've / we've + participio · she's / he's + participio

      I've finished · I've checked it twice · I haven't seen it yet · Have you ever…?

      Con palabras: just (acabo de), already (ya), yet (todavía, al final), ever / never, for (durante) + tiempo, since (desde) + momento.

      Diferencia con el pasado: si dices cuándo (yesterday, at 3, last week), usa pasado simple: I checked it yesterday.

      Primer condicional: algo real o probable B1

      If + presente, will + verbo · If it's out of limits, I'll reject it.

      Igual con when, as soon as (en cuanto), unless (a menos que): I'll call you as soon as it arrives. Después de estas palabras, presente, nunca will.

      Segundo condicional: imaginar B2

      If + pasado, would + verbo · If I had more time, I would check it again.

      If I were you, I'd ask the supervisor. (Con if, "were" para todos).

      would para pedir con educación: Would you mind checking this? · I'd like a copy.

      Used to / would like B1

      used to + verbo = solía · I used to work in Madrid.

      be used to + -ing = estar acostumbrado · I'm used to working nights.

      would like / I'd like + to + verbo = me gustaría · I'd like to ask something.

      -ing o to + verbo B1–B2

      + -ingfinish, enjoy, avoid, suggest, mind, keep, start, stop, look forward to · Avoid touching the blade.
      + towant, need, try, decide, plan, forget, agree, promise, would like · I need to check it.
      cambia el sentidoremember to (acordarse de hacer) / remember -ing (recordar haber hecho) · stop to (parar para) / stop -ing (dejar de)

      Después de preposición, siempre -ing: before starting, without asking, thanks for helping.

      had + participio · When I arrived, they had already started.
